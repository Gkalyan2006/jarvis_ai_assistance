Jarvis AI Assistance — Phase One

Simple demo dashboard. Use the API endpoints to interact programmatically.

  • Health: /api/health
  • Transcribe (POST): /api/voice/transcribe — records ~5s and returns transcript
  • Ask (POST): /api/ask — JSON {"prompt":"..."}
  • Automation (POST): /api/automation/run — JSON {"cmd":"dir"} or {"app":"C:/Program Files/"}, header x-api-token
